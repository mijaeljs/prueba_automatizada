# Página Web Institucional - I.E. 7096 "Príncipe de Asturias"

## Descripción del Proyecto

Este proyecto consiste en el desarrollo de una página web institucional para la Institución Educativa 7096 "Príncipe de Asturias". Su propósito es proporcionar información relevante a estudiantes, padres de familia y comunidad en general mediante una plataforma web moderna, organizada y accesible.

La página ha sido diseñada para mejorar la presencia digital de la institución, permitiendo difundir información institucional, logros, datos de contacto y otros contenidos de interés para la comunidad educativa.

## Objetivo General

Desarrollar una página web institucional que facilite la difusión de información y fortalezca la comunicación entre la institución educativa y la comunidad.

## Tecnologías Utilizadas

* HTML5
* CSS3
* Bootstrap 5
* JavaScript
* Git
* GitHub
* Visual Studio Code

## Funcionalidades

* Página de inicio con información principal de la institución.
* Sección "Acerca de Nosotros".
* Visualización de logros institucionales.
* Formulario de contacto.
* Interfaz de acceso (Login).
* Navegación intuitiva entre las diferentes secciones.
* Diseño moderno basado en Bootstrap.
